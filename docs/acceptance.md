# Experimental release acceptance

The implementation is an experimental runtime. The README recording and final release
packet are not complete. This register separates observed behavior from remaining work.

| Area             | Current evidence                                                                                                                                                                  | Remaining work or limitation                                                                                                                             |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durable cells    | Named graphs, aliases, helpers and handles survive eviction; Kimi-generated data/helper reused by GLM after compaction and actual restart                                         | Large-scale namespace and storage stress tests                                                                                                           |
| Journal/recovery | Approval replay, uncertain effects, reconciliation, stale/version divergence, omitted-operation rejection; actual mid-cell crash after a durable effect receipt                   | Broader connector-specific reconciliation cases                                                                                                          |
| Isolation        | Current grants, inherited lineage, private artifacts, controlled publication, scoped children, parent revocation and operator-workspace cases                                     | Broader distributed-policy and revocation matrix; workspace lineage is deliberately conservative                                                         |
| Context          | Retained originals, SQLite FTS, exact/around lookup, bounded model requests, retrievable tool-round receipts; three-strategy synthetic comparison                                 | Provider-native adapter and reactive provider-overflow continuation are not yet verified                                                                 |
| Activity         | Customer/developer projections, persisted chunk outbox, WebSocket replay/deduplication, transaction-ordered delivery, test transport callback                                     | Additional production transports are adapters to implement                                                                                               |
| MCP              | Cloudflare client, encrypted OAuth/PKCE storage, catalog versions; real HTTPS refresh after restart, revocation, reconnection and original-cell resumption                        | Only the synthetic provider and controlled transport cases have been exercised                                                                           |
| Learning         | Resumable three-candidate pipeline, structured/cited grouping, embedding-ranked candidates, protected evaluation, held-out assessment and rollback; real-model improvement passed | Larger outcome datasets; infrastructure application is intentionally outside automatic promotion                                                         |
| Delegation       | Durable identities, mailboxes, immutable results, inherited authority and shared root budget; separate deterministic supplier agents                                              | Broader model-driven multi-agent interruption cases                                                                                                      |
| Reference UI     | PO/quoting workflows, approvals, workspace output, learning, capabilities, knowledge and permission controls through real APIs                                                    | Final recording/story polish; private observation UI is not provided by the public synthetic app                                                         |
| Observation      | GET-only collector and private file store tested; private CDC sample retained outside Git                                                                                         | Live authenticated HTTP collector verification and fuller historical replay coverage; bounded private PO and quoting CDC samples are retained separately |
| Documentation    | Runnable quickstart recipe compiled and exercised in Workers; API/deployment/MCP/observation guides                                                                               | Final rendered README video readback                                                                                                                     |
| Comparisons      | Actual Codemode/Shell + GEPA learning study and three context strategies; results and limitations documented                                                                      | No statistically meaningful superiority, human integration-effort, or review-effort result                                                               |
| Release          | Public repository and isolated deployed resources                                                                                                                                 | Recordly capture, MP4/README asset, final release packet                                                                                                 |

No private observation evidence may enter the public repository or public deployment.
The first learning study found no quality advantage over Codemode + GEPA. Further
architectural expansion should be justified by representative integration/recovery evidence.
